# Neon Apex

A small 2D endless racing game built with vanilla HTML, CSS, and JavaScript. Dodge traffic, survive as long as possible, and beat your best score.

## Play locally

Open `index.html` in a browser, or serve the folder with any static web server.

- Desktop: use Left/Right arrows or A/D to steer, and hold Space to boost.
- Mobile: use the on-screen steering buttons.
- Press Enter to start or restart.

## Publish on GitHub Pages

1. Create a GitHub repository and push this folder to its `main` branch.
2. In the repository, open **Settings > Pages**.
3. Set the source to **GitHub Actions**.
4. The included workflow deploys the game automatically on every push to `main`.
